# VISION.md — 项目愿景

## 产品定位

个人基金投资管理系统，基于 E大（ETF拯救世界）投资理念，帮助管理基金持仓、网格策略、交易记录和投资分析。

## 目标用户

投资者本人（单用户模式）。

## 核心价值

1. **持仓透明** — 从交易记录派生批次持仓，实时查看浮动/已实现盈亏
2. **网格策略** — 自动化网格交易执行、状态追踪、盈亏计算
3. **投资分析** — 资产配置可视化、技术指标、回测
4. **数据主权** — 所有数据存储在自己的 Supabase 实例，支持导出/备份

## 可交付标准（对齐共识）

**对抗性收敛**：每轮主动挖真实缺陷（bug/静默失败/安全/逻辑不一致）并修复到测试全绿；可改核心业务逻辑但必须测试守护（先写失败测试、542 测试全绿、不改交易语义）；不引入新依赖；最多 10 轮。目标是"对抗审查无可击破"，而非维持分数。

## 当前阶段

v2.8.0，上轮打磨已让全维度 ≥7 收敛。本轮为**第二轮对抗性打磨**——重新诚实评分，主动寻找上轮遗漏的真实缺陷。
